# M2N2: Test-time Adaptation (`m2n2`)

- **Category:** main
- **Paper:** When Model Meets New Normals: Test-time Adaptation for Unsupervised Time-series Anomaly Detection — AAAI 2024 (doi:10.1609/aaai.v38i12.29210, arXiv:2312.11976). (The registry title differs.)
- **Official code:** https://github.com/carrtesy/M2N2
- **Fidelity verdict:** ADAPTATION — honestly labelled "M2N2-Lite"; a val/test EMA leak was fixed 2026-08-21
- **Core idea:** An autoencoder scores reconstruction error on frozen features while an EMA "detrender" tracks the running mean of the incoming stream and subtracts it, adapting to new normals. Higher reconstruction error = OOD.
- **Key parameters:** EMA recurrence `γ·trend + (1−γ)·feat` (arithmetically identical to the official `Detrender`); `gamma = 0.995`; trend snapshotted at fit and **reset at the start of every `score()`** (post-fix); test-time adaptation off by default (matches official `infer_options: ["offline"]`); per-window scalar score; higher = OOD.
- **Divergences from original / caveats:**
  - Fix eliminated a leak where the sequential EMA `trend_mean` mutated during the val pass and was never reset before the test pass; each split is now independent and reproducible.
  - Two things the tracker flagged as divergences are actually **agreements** with the official defaults: adaptation off, and per-sample (`eval_batch_size=1`) processing.
  - Genuine divergences (disclosed): frozen-feature input domain, fixed MLP AE, unconditional (always-on) detrending, trend initialised to the training mean not zeros, per-window rather than per-timestep scores. The inert TTA path differs in threshold/selection/lr.
  - Sequential EMA makes scores mildly order-dependent (~5% mean deviation, ρ≈0.97). `gamma` docstring inconsistent across the file (operative value 0.995).
  - Second-strongest verified detector (TSB-U 0.795, 4/21 below chance); full fidelity to raw-series TTA still needs an ordered stream.
- **Where it runs:** `models/detectors/m2n2.py`
